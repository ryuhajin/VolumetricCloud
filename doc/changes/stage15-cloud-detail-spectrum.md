2026-09-22 사용자 후속 지시. E17의 대역 결합만 변경한 후보는 개선 근거가 없어 종료했고,

시험 후보는 각 채널의 현재 주파수 f에 2f/4f를 추가한 정규화 Worley fBm(.625/.25/.125)이다.

후보0=현재 단일 Worley,1=fBm,2=고정 Near75 단면의 평균 제거량을 맞춘 fBm.
원본8프리셋/일반 실행을 보존하고 비교 자료를 만든다. 화면 품질 채택은 기존 사용자 게이트에 따른다.
이전 해상도32/64·Detail 크기±10%·Base 옥타브와 다른 입력 변경이며 같은 격자를 반복하지 않는다.

## 문제와 바꾼 부분

E17은 이미 들어 있는 네 채널을 섞는 식만 바꿨고 개선 근거가 없었다.
우리 원본은 채널마다 단일 Worley 거리인 반면, 참조 프로젝트는 채널 내부에 여러 대역을 합친다.
이번은 생성 입력 자체를 바꾸는 실험이며 참조의 밀도식/해상도/광학계수 전체 재현은 아니다.
참조 코드와 고정 커밋은 [E17의 소스 분석](stage15-cloud-detail-band-composition.md#이번-결과로-수정한-다음-조사-방향)에 기록했다.

`NoiseVolume.hlsl`의 시험 CSDetail만 `W(f) → .625W(f)+.25W(2f)+.125W(4f)`로 바꾼다.
W는 주기적인 Worley 거리, f는 채널별2/3/4/5 cycle/타일이다. 각 대역의 seed/위상 오프셋19는
기존 규칙을 유지한다. 가중치 합1은 평균값 범위를 유지하지만 값의 분산까지 유지하지는 않는다.
새로운 무늬를 Texture3D에 미리 담으므로 프레임의 texture 조회 횟수는 같다.
다만 실제 구름 점유/early exit가 바뀔 수 있으므로 프레임 비용이 같다고 판정하지 않는다.

원본은 그대로 보존하고 별도64³ RGBA8 텍스처/SRV를 생성한다. `CloudDetailBands.inl`에서 후보별로
교체하며 실패/정상 종료 모두 원본 리소스/SRV/hash와 카메라/렌더 상태를 복원한다.
새 UI/CB/프리셋 schema는 없고 일반 컴파일에서는 시험 정의가 없다.
`Noise.hlsli`의 시험 계수는 e에만 곱하며 S/A/몸체보호/최종 shaping은 승인 remap 그대로다.

초기 실행 `27984-16730562`는 FXC X3511(펼친 루프가 너무 큼)로 실패했다. 비교 근거에서 제외한다.
벡터 채널 쓰기는 동적 주소가 불가능해 채널 loop 방식도 FXC X3531로 거부되었다.
최종 구현은 시험 생성기의 Worley z 이웃 탐색에만 loop를 유지한다. 일반 생성기는 기존 unroll이다.
수학적 결과는 기존 double CPU Worley 구현과 경계 포함512 voxel×4채널로 대조한다.

## 결과: 고주파는 증가했지만 선명도 개선 근거는 부족

| 저장 Detail 가중합 | 현재 | fBm |
|---|---:|---:|
| 평균 | .449938 | .450834 |
| 표준편차 | .086128 | .056369 |
| FFT 에너지 중 반경8 cycle/tile 이상 비율 | .41% | 2.52% |

작은 무늬의 상대적 에너지는 늘었지만 전체 값의 표준편차는 약34.6% 줄었다.
여러 무늬를 평균내면 큰 값/작은 값이 서로 상쇄되는 효과가 있다. 이는 생성된 voxel에 관한 결과이며
화면의 선명도나 aliasing을 증명하지 않는다. Worley는 대역 제한 함수도 아니다.

k1의 Near75 제거량은 기준보다2.161% 크다. k=.981983208로 맞춘 후보2는
보정/미사용 홀수 모두 −.040%, 별도 공간 F5는 −.860%다. 평균 제거량이 같아도 공간 분포는 다르다.

대비는 대기 제외 영상에서 기준 Alpha .2~.9의 고정 마스크에 대한 (P90−P10)/(P90+P10)이다.
보정 후보는 외곽 대비 약3.3%, 파임 약19.9%, 몸체 약16.2% 감소했다.
보정 후에도 파임 Alpha가 .3730→.4087로 늘어 그 영역은 더 채워졌다.
고정 외피 위치에서 단면 밀도 기울기는9단면 중8개가1.22~13.07% 감소, 하나만1.42% 증가했다.
이는 화면 법선 경계 폭이나3D 전체 연결성을 측정한 값이 아니다.

**현재 권고: 이 정규화 fBm을 일반 기본값으로 채택하지 않는다.** 작은 굴곡의 변화는 있지만
근경 선명도 해결로 볼 수 없고, 특히 파임 대비가 떨어진다. 화면의 최종 평가는 사용자에게 남긴다.
같은 계수를 무작정 늘리기보다, 후속 주파수 실험을 한다면 이번에 확인된 **값 분포의 평준화**를
분리해야 한다. 평균 제거량 일치만으로 분산/공간 경계를 일치시킬 수는 없다.
이번 실행에서 추가 분포 재매핑/높이/조명 후보는 섞지 않았다.

## 2026-09-22 사용자 채택: 무보정 fBm

사용자 지시: “기본 노이즈 값은 fbm으로 확정하자.” 후보1을 채택하고 후보2의 제거량 보정은 적용하지 않는다.
두 후보는 같은64³ fBm 텍스처를 읽는다. 후보1의 침식량을 e라고 할 때 후보2는 약.981983208e를 사용한다.
이는 침식 문턱을 약1.8% 낮춘 것이며 최종 밀도를 일률적으로1.8% 늘린다는 뜻이 아니다.
보정은 Near75 단면의 shaping 후 Base−최종밀도 총합을 옛 단일 Worley 기준에 맞춘 진단용 절차다.
모든 위치/광선의 Alpha나 명암이 기존과 같아지는 보정이 아니다.

해결한 입력 차이는 채널 내부에 작은 주파수 대역이 없던 점이다. 채택 후 각 채널은
